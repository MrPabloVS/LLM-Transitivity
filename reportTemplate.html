02 / DOS DIMENSIONES DISTINTAS

Dar la respuesta y respetar el formato

La decisión explícita se extrae mediante reglas conservadoras. El formato estricto se mide con el normalizador original: solo yes o no, admitiendo mayúsculas, espacios exteriores y puntos finales.

Una respuesta con explicación puede ser correcta y, a la vez, incumplir el formato. No se evalúa aquí si cada paso de la explicación es correcto. La precisión sobre interpretables excluye filtros y respuestas sin decisión extraíble; se muestra junto con su cobertura.

05 / CÓMO LEER EL INFORME

Método, procedencia y límites

1. Dos referencias, una fuente intacta

La auditoría enumera las asignaciones de verdad, tratando cada cláusula distinta como una proposición atómica independiente. Un argumento es inválido si alguna asignación hace verdaderas ambas premisas y falsa la conclusión.

Las variantes no canónicas presentan Q → R, P → Q y concluyen R → P. La conclusión no se sigue de esas premisas. Se conservaron todos los prompts y etiquetas originales.

Hay 1.500 discrepancias en las 4.500 filas de origen de presente; esas filas generan 4.500 observaciones al evaluarse con tres modelos.

2. Extracción explícita y auditable

Primero se acepta la respuesta normalizada directa. Para textos más largos se busca una decisión yes/no explícita al inicio, seguida de puntuación, o una última línea formada solo por la respuesta; se admite Markdown y el prefijo Answer:.

Si las señales discrepan, se marca conflicto. Sin señales, el caso queda sin resolver. No se deduce una decisión a partir de frases como “yes or no” ni se interpreta el razonamiento completo. Cada extracción conserva su regla y evidencia.

3. Denominadores separados

  • Corrección principal: correctas / todos los registros seleccionados.
  • Cobertura: decisiones extraíbles / todos los registros.
  • Precisión sobre interpretables: correctas / decisiones extraíbles.
  • Formato: respuestas directas normalizadas / todos los registros.

Los filtros del proveedor son resultados terminales con texto nulo. No son una respuesta no ni se ocultan del denominador principal.

4. Una ejecución, con límites

GPT/LF reutiliza 211 resultados históricos y añade 1.289 nuevos; no representa una repetición independiente realizada enteramente en la misma fecha. Las variantes comparten IDs y no deben tratarse como 1.500 réplicas independientes.

No se fijaron temperatura ni semilla, y no hay repeticiones nuevas. No se atribuye causalidad al vocabulario, no se realizan pruebas de significancia ni se generaliza este resultado a otros prompts o modelos.
